# 蜀牌局 · 四川麻将

一个只在本地运行的四川麻将牌桌，支持好友房、同一局域网多设备联机，以及单人补齐三位智能牌友快速试玩。

## 已实现

- 6 位房号创建、加入、断线重连与多窗口实时同步
- 换三张、顺/逆时针与对家换牌
- 定缺与必须先打缺门牌的校验
- 摸牌、出牌、碰、明杠、暗杠、荣和、自摸
- 血战到底、刮风下雨计分与单局结算
- 智能牌友自动选牌、定缺、摸打和响应
- 桌面与移动端自适应牌桌、快捷消息、规则说明

## 本地启动

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可。默认网页端口通常为 `3000` 或 `3001`，实时房间服务使用 `8788`。

同一台电脑可打开多个浏览器标签模拟多人加入；同一局域网内的其他设备可打开终端显示的 `Network` 地址，再输入房号加入。

## 验证

```bash
npm test
```

该命令会执行正式构建，并验证页面渲染、麻将牌素材完整性，以及两个本地客户端创建/加入/开局的联机流程。
